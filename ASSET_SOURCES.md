# Product brand assets

The product cards display the brand artwork itself over a separate lightweight local CSS/SVG card background.

- Netflix: Wikimedia Commons, sourced from Netflix's official brand assets — https://commons.wikimedia.org/wiki/File:Netflix_Logomark.png
- Disney+: current 2024 Disney+ logo variant — https://commons.wikimedia.org/wiki/File:Disney%2B_Original_%282024%29.svg
- Spotify: Spotify official Media Kit / Brand Assets — https://newsroom.spotify.com/media-kit/logo-and-brand-assets/
- Discord: Discord official Brand Guidelines — https://discord.com/branding
- Roblox: Wikimedia Commons, source listed as Roblox — https://commons.wikimedia.org/wiki/File:Roblox_Logo.svg
- VALORANT: Wikimedia Commons, source listed as playvalorant.com / Riot Games — https://commons.wikimedia.org/wiki/File:Valorant_logo.svg

The site keeps a bundled local fallback for each product so a remote brand-asset host failure does not produce an empty card.
